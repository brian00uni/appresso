# Writing Studio

네이버 블로그 **반자동 글쓰기 봇**. 콘텐츠(제목·본문·이미지)는 자동 생성하고
스마트에디터 ONE에 자동으로 채워넣기까지 하되, **최종 발행 버튼은 사람이** 누른다.

> 왜 반자동인가?
> 네이버는 개인 블로그용 공식 글쓰기 API가 없어 브라우저 자동화(Playwright)로 스마트에디터를
> 조작해야 한다. 아이디/비번 자동 로그인·짧은 간격 반복 포스팅은 비정상 로그인/매크로로 탐지돼
> 캡차·계정잠금·저품질 처리로 이어질 수 있다. 그래서 **① 세션 쿠키 재사용(1회 수동 로그인)**,
> **② 발행은 사람이 딸깍(또는 네이버 예약발행)** 방식으로 계정 리스크를 최소화한다.

## 아키텍처 (목표)

```
[주제/키워드 입력]
   → [Gemini API로 본문 생성]  제목·본문·태그·이미지 프롬프트
   → [이미지 준비]            AI 생성 or 내 이미지 폴더 매칭
   → [Playwright: 저장된 세션으로 로그인 상태 진입]
   → [스마트에디터 ONE 자동 입력]  제목/본문(클립보드 붙여넣기)/이미지 업로드
   → [임시저장 상태로 멈춤]    ← 사람이 검수 후 발행
```

## 현재 구현 (v0.1 — 뼈대 + 세션)

| 명령 | 설명 |
|------|------|
| `npm install` | 의존성(Playwright) 설치 |
| `npm run login` | 크롬 창에서 **1회 수동 로그인** → 세션을 `auth/naver.session.json` 에 저장 |
| `npm run check` | 저장된 세션이 아직 로그인 상태로 유효한지 확인 |

### 처음 설정

```bash
cd writingStudio
npm install
npx playwright install chromium   # 브라우저 바이너리 (이미 있으면 생략됨)
npm run login                     # 열린 창에서 네이버 로그인 → 자동 저장
npm run check                     # 세션 확인
```

## 보안 주의

- `auth/` 폴더의 세션 파일에는 **로그인 쿠키/토큰이 들어 있습니다. 절대 커밋·공유하지 마세요.**
  (`.gitignore` 로 이미 제외됨)
- 세션은 시간이 지나면 만료됩니다. 만료 시 `npm run login` 을 다시 실행하세요.
