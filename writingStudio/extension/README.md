# Writing Studio — 크롬 확장앱 (네이버 블로그 AI 글쓰기)

AI(Gemini)로 블로그 글을 생성하고 **스마트에디터 ONE**에 자동으로 채워주는 크롬 확장앱.
**발행은 사람이** 검수 후 직접 합니다.

## 왜 확장앱인가

내 브라우저 안에서 돌아가므로:
- 네이버 **로그인을 자동화하지 않음** — 이미 로그인된 브라우저를 그대로 사용 (캡차·계정잠금 걱정 없음)
- 데이터센터 IP가 아닌 **내 IP·내 브라우저** → 안전
- 채워진 글을 **직접 보고 발행** → 저품질/오발행 방지
- 설치가 쉬움 — Node·터미널 불필요

## 설치 (개발자 모드)

1. 크롬 → `chrome://extensions`
2. 우측 상단 **개발자 모드** ON
3. **압축해제된 확장 프로그램을 로드** → 이 `extension` 폴더 선택
4. 우측 상단 퍼즐 아이콘 → **Writing Studio** 핀 고정

## 사용법

1. 아이콘 클릭 → 사이드패널 열림
2. **Gemini API 키** 저장 (aistudio.google.com → “Get API key”, 무료)
3. **주제 / 키워드 / 톤 / 내용 프롬프트** 입력 → **글 생성하기** → 미리보기 확인
4. 네이버 블로그 **글쓰기 페이지**를 연 뒤 → **에디터에 채우기**
5. 열린 에디터에서 검수하고 **직접 발행**

## 구성

| 파일 | 역할 |
|------|------|
| `manifest.json` | MV3 설정 (sidePanel, content script, host_permissions) |
| `background.js` | 아이콘 클릭 시 사이드패널 열기 |
| `sidepanel.html` / `sidepanel.js` | UI + Gemini 생성 + 채우기 요청 |
| `content/naver-fill.js` | 글쓰기 페이지에서 제목·본문 자동 입력 |

## 참고

- Gemini 무료 티어는 분당/일일 요청 한도가 있어요. 한도 초과 시 잠시 후 재시도.
- 스마트에디터 셀렉터: `../SELECTORS.md` 참고. 사이트 레이아웃 변경 시 `content/naver-fill.js` 조정 필요.
