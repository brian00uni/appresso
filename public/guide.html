설치 방법

🖥 사전 요구사항

🌐 크롬 브라우저

Google Chrome (최신 버전 권장)
또는 Chromium 기반 브라우저

🤖 Google 계정

Google Flow (labs.google/flow) 접근 가능한 계정 필요

📦 개발자 모드로 설치 (압축 해제 상태)

1
확장 프로그램 관리 페이지 열기

Chrome 주소창에 chrome://extensions 를 입력하고 Enter

2
개발자 모드 활성화

페이지 우측 상단의 "개발자 모드" 토글을 켭니다.

3
"압축 해제된 확장 프로그램 로드" 클릭

좌측 상단에 나타나는 버튼을 클릭합니다.

4
폴더 선택

빌드 폴더를 선택합니다. (내부에 manifest.json이 있는 폴더)

⚠️ 중요: Flow에서 반드시 새 프로젝트를 생성한 뒤, 해당 프로젝트 폴더 내에서 사용해야 합니다. 프로젝트 폴더 밖에서 실행하면 기능이 정상 동작하지 않습니다.
5
설치 확인

확장 프로그램 목록에 Art Studio Flow 자동화가 표시되면 설치 완료!

6
사이드패널 고정 (선택)

Chrome 우측 상단 퍼즐(🧩) 아이콘 → Art Studio를 찾아 핀 고정하면 편리합니다.

💡 팁: 확장 프로그램 아이콘을 클릭하면 사이드패널이 열립니다. Chrome의 사이드패널 기능이 필요하므로 Chrome 114 이상을 권장합니다.
2

화면 구성 (UI 개요)

  • 🔴
    헤더 — 연결 상태 표시 현재 Google Flow와의 연결 상태를 실시간으로 표시합니다. Off-line / On-line
  • ✍️
    프롬프트 입력 생성할 프롬프트를 텍스트로 입력하거나, JSON 파일로 불러올 수 있습니다.
  • ⚙️
    Flow 설정 모드(이미지/동영상), 비율, 수량, AI 모델 등을 설정합니다.
  • 🔧
    작업 설정 딜레이(생성 대기 시간), 파일명 접두어, 참조 이미지, 자동 다운로드 여부를 설정합니다.
  • ▶
    작업 버튼 시작 / 일시정지 / 스킵 / 중지 버튼으로 작업을 제어합니다.
  • 📊
    진행 상태 프로그레스 바와 메시지로 현재 진행 상황을 실시간 확인합니다.
  • 🏷️
    미디어 이름 변경 Google Flow 프로젝트 페이지에서 미디어 파일명을 순차 자동 변경합니다.
⚠️ 주의: 헤더의 상태 표시가 Off-line(빨간색)인 경우, 프롬프트·설정·실행·이름 변경 등 모든 기능이 비활성화됩니다. 먼저 Flow 페이지를 열고 연결해야 합니다.
3

Google Flow 연결하기

1
🚀 Flow 열기 버튼 클릭

헤더 우측의 "🚀 Flow 열기" 버튼을 클릭하면 Google Flow(labs.google/flow)가 새 탭에 열립니다.

2
Google 계정 로그인

Flow 페이지에서 Google 계정으로 로그인합니다. 이미 로그인되어 있다면 바로 사용 가능합니다.

3
연결 상태 확인

사이드패널 헤더의 상태 표시가 On-line (초록색)으로 바뀌면 연결 완료. 모든 기능이 활성화됩니다.

💡 참고: 연결 상태는 Flow 페이지가 열려 있는 동안에만 유지됩니다. Flow 탭을 닫으면 다시 Off-line 상태가 됩니다.
4

프롬프트 입력

생성할 내용을 입력하는 방법은 3가지입니다.

① 텍스트 직접 입력

📝 기본 텍스트 모드

큰 입력창(textarea)에 프롬프트를 한 줄에 하나씩 입력합니다.
각 줄이 하나의 생성 작업으로 처리됩니다.

A futuristic city skyline at night with neon lights A cozy coffee shop interior with warm lighting Abstract wave patterns in vibrant colors

하단의 "프롬프트 N개" 카운터로 줄 수를 확인하세요.

② JSON 파일 불러오기 추천

📂 JSON 모드

"📂 JSON" 버튼을 클릭하여 scene JSON 파일을 불러옵니다. 여러 파일을 동시 선택해 큐에 추가할 수 있습니다.

  • JSON 파일 내 "prompt" 필드 값이 자동으로 추출됩니다.
  • 큐 목록에서 순서 확인, "전체 삭제" 버튼으로 초기화 가능합니다.
// scene_01.json 예시 { "scene": "EP01 - Scene 01", "duration": "8 seconds", "prompt": "Extreme photorealistic RAW video of a lone traveler walking through a misty forest..." }

③ JSON 텍스트 붙여넣기

📋 붙여넣기 모드

"📋 붙여넣기" 버튼 클릭 → 텍스트 영역에 JSON 내용을 직접 붙여넣기 → 파일명 입력 후 "추가".

파일을 따로 저장할 필요 없이 빠르게 큐에 추가할 수 있습니다.

🌐 자동 영문 번역

"🌐 영문 번역" 체크박스를 켜면 한국어 프롬프트가 작업 전 자동으로 영문 번역됩니다.
Flow AI는 영어 프롬프트에서 더 좋은 품질을 출력하므로 켜두는 것을 권장합니다.

🎨 스타일 프롬프트 (선택)

모든 프롬프트에 공통으로 추가되는 스타일 텍스트입니다.
예: cinematic lighting, 8K, photorealistic, sharp focus

작업 설정

⏱ 생성 대기 시간

이미지 생성 시간 (초) — 최솟값 ~ 최댓값

각 이미지가 생성될 때 기다리는 시간 범위입니다. (기본: 15 ~ 20초)

  • 너무 짧으면 생성 완료 전에 다음 단계로 넘어가 오류 발생 가능
  • 네트워크 속도나 서버 부하에 따라 20~30초로 늘리는 것을 권장
  • 동영상 생성 시에는 훨씬 긴 시간이 필요하며, 확장이 자동으로 완료를 감지합니다

🏷 이미지 파일명 접두어

자동 다운로드 시 파일명의 앞부분에 붙을 텍스트입니다. (기본: ArtStudio_)

예: Scene_ 입력 시 → Scene_001.jpg, Scene_002.jpg...

🖼 참조 이미지

참조이미지 체크박스

체크 시 Flow 프로젝트의 에셋을 참조 이미지로 사용합니다.

  • 이미지 모드: 최대 10개의 에셋 검색명을 슬롯에 입력
  • 동영상 프레임 모드: 단일 에셋 검색명 입력
  • 에셋 검색명은 Flow 프로젝트에 업로드된 에셋 파일명의 일부입니다

🔚 종료 프레임 (동영상 전용)

동영상의 끝 프레임(마지막 장면)을 별도 에셋으로 지정합니다.
시작 프레임과 종료 프레임을 모두 고정해 씬 전환을 정밀하게 제어할 수 있습니다.

⬇️ 자동 다운로드

체크 시 생성 완료된 이미지가 자동으로 로컬 다운로드 폴더에 저장됩니다.
(기본값: 켜짐)

작업 실행 및 제어

▶ 작업 시작

1
프롬프트와 설정 확인

입력창에 프롬프트가 있고, Flow 설정이 완료되었는지 확인합니다.

2
Flow 탭이 열려 있는지 확인

헤더가 On-line 상태여야 합니다.

3
"▶ 작업 시작" 버튼 클릭

자동으로 Flow 탭으로 이동하며 생성을 시작합니다. 진행 상태가 실시간으로 업데이트됩니다.

🎮 작업 제어 버튼

버튼기능
▶ 작업 시작큐의 첫 번째 프롬프트부터 자동 생성 시작
⏸ 일시정지현재 작업 완료 후 다음 작업을 대기 상태로 멈춤
⏭ 스킵현재 진행 중인 작업을 건너뛰고 다음으로 이동
⏹ 중지모든 작업을 즉시 중단

📊 진행 상태

  • 프로그레스 바: 전체 작업 중 완료 비율 시각화
  • 카운터: 현재 / 전체 형식으로 표시
  • 상태 메시지: 현재 처리 중인 작업 내용 표시
💡 자동 다운로드: 작업 설정에서 "자동 다운로드"를 켜두면 생성 완료 즉시 파일이 저장됩니다. Chrome의 다운로드 위치는 Chrome 설정 → 다운로드에서 변경할 수 있습니다.
8

미디어 이름 변경

Google Flow 프로젝트 페이지에서 미디어 파일명을 순차적·자동으로 일괄 변경하는 기능입니다.

🔄 동작 방식

목록의 맨 아래(가장 오래된 파일)부터 위로 올라가며 순서대로 이름을 변경합니다.

예: 접두어 scene_, 총 갯수 8 입력 시

// 결과: 아래부터 위로 scene_01, scene_02, scene_03, ... scene_08

📋 사용 방법

1
Flow 프로젝트 페이지로 이동

labs.google/flow 에서 변경하려는 프로젝트를 엽니다.

2
접두어 입력

"접두어" 입력창에 파일명 앞에 붙일 텍스트 입력. (예: scene_)

3
총 갯수 입력

변경할 미디어 파일의 총 개수를 입력합니다. (예: 30)

4
"🏷️ 이름 변경 시작" 클릭

자동으로 프로젝트 미디어 목록에서 순차 변경을 시작합니다.
중간에 멈추려면 "⏹ 중지"를 클릭합니다.

⚠️ 주의: 반드시 프로젝트 페이지에서 사용해야 합니다. Flow 메인 화면에서는 작동하지 않습니다. 이름 변경은 되돌리기 어려우니 파일 수를 정확히 확인 후 실행하세요.
9

효율적인 사용 팁

💡 JSON 구조로 씬 관리하기

각 씬을 별도의 JSON 파일로 분리하면 재사용과 관리가 편리합니다. "prompt" 필드만 있으면 어떤 JSON 구조도 지원됩니다.

⏱ 딜레이 설정 최적화
  • 이미지: 15~20초 (기본값, 네트워크 느리면 25~30초)
  • 동영상: 완료 감지 자동화로 딜레이가 덜 중요하지만, 20초 이상 유지 권장
🔗 참조 이미지 활용

캐릭터나 스타일 일관성이 중요한 경우, 참조 이미지를 Flow 에셋에 미리 업로드하고 에셋 검색명을 입력하면 효과적입니다.

📦 배치 처리 전략

긴 프로젝트(30씬 이상)는 10~15씬씩 나눠 배치로 처리하면 오류 발생 시 롤백이 쉽습니다. 중간에 "스킵"으로 문제 씬을 건너뛸 수 있습니다.

🌐 한국어 프롬프트 + 영문 번역

프롬프트를 한국어로 작성하고 "🌐 영문 번역"을 켜면 자동으로 영문 번역 후 생성됩니다. AI 생성 품질이 영문에서 더 높은 경향이 있습니다.

🔄 이름 변경 후 다운로드 연동

생성 완료 후 이름 변경 기능으로 파일명을 정리하면 편집 작업 시 씬 순서 관리가 훨씬 쉬워집니다. scene_01, scene_02... 형식을 추천합니다.

10

자주 묻는 질문 (FAQ)

Q. Off-line 상태에서 아무것도 안 됩니다.

A. "🚀 Flow 열기" 버튼을 클릭해 Google Flow 탭을 열고, 로그인한 뒤 사이드패널이 On-line으로 바뀌는지 확인하세요. Flow 탭이 열린 상태를 유지해야 합니다.

Q. 생성이 시작되지 않습니다.

A. 프롬프트 입력창이 비어있는지 확인하고, 프롬프트 수 카운터("프롬프트 N개")가 0보다 큰지 확인하세요. JSON 큐 모드라면 큐에 항목이 있는지 확인하세요.

Q. 자동 다운로드가 안 됩니다.

A. 작업 설정의 "자동 다운로드" 체크박스가 켜져 있는지 확인하세요. Chrome 설정에서 다운로드 위치를 특정 폴더로 지정해 두면 더 편리합니다.

Q. 딜레이 시간 중에 오류가 발생합니다.

A. 딜레이 최솟값을 올려보세요 (예: 20 → 30). 네트워크 속도나 서버 부하에 따라 생성 시간이 달라집니다.

Q. 이름 변경이 프로젝트 페이지에서 작동하지 않습니다.

A. labs.google/flow의 프로젝트 내부 페이지에서만 동작합니다. 메인 홈이 아닌 개별 프로젝트 페이지인지 확인하세요.

Q. JSON에서 prompt 필드가 없으면 어떻게 되나요?

A. prompt 필드가 없는 JSON 파일은 로드 시 오류 메시지가 표시되고 큐에 추가되지 않습니다. JSON 파일에 반드시 "prompt" 키가 있어야 합니다.

Q. 확장 프로그램 업데이트는 어떻게 하나요?

A. 새 버전을 받으면 ArtStudio_autoflow_amor 폴더의 내용을 교체한 뒤, chrome://extensions에서 해당 확장 프로그램의 새로고침(🔄) 버튼을 클릭합니다.
