📝 Writing Studio 사용 가이드

AI로 네이버 블로그 글을 쓰고 스마트에디터에 자동으로 채우는 크롬 확장앱

안전 설계 — 내 브라우저의 네이버 로그인을 그대로 사용하므로 아이디/비번 자동 로그인이 없고, 발행은 사람이 직접 검수 후 합니다. 자동 발행하지 않아 계정 리스크가 낮아요.

1. 설치

  1. 랜딩 페이지의 “확장앱 다운로드 (.zip)” 버튼으로 zip을 받습니다.
  2. zip을 풀어 writing-studio 폴더를 만듭니다.
  3. Chrome 주소창에 chrome://extensions 입력 → 우측 상단 개발자 모드 ON
  4. “압축해제된 확장 프로그램을 로드” → writing-studio 폴더 선택
  5. 목록에 Writing Studio가 뜨면 완료 → 퍼즐 아이콘에서 핀 고정

2. Gemini API 키 (무료)

글 생성은 Google Gemini 무료 티어로 동작해요. 카드 등록 없이 무료로 시작할 수 있습니다.

  1. aistudio.google.com 접속 → 구글 로그인
  2. “Get API key” → “Create API key”
  3. 발급된 키를 복사
  4. 확장앱 아이콘 클릭 → 사이드패널의 🔑 Gemini API 키에 붙여넣고 키 저장
무료 티어는 분당/일일 요청 한도가 있어요. 한도 초과 시 잠시(1분쯤) 뒤 다시 시도하면 됩니다.

3. 글 생성

1주제 입력 (예: 초보자를 위한 가계부 쓰는 법)

2키워드(선택) · 톤/느낌 선택 (친근하게 / 후킹 강하게 / 여성스럽게 …)

3내용 프롬프트(선택) — 글에 꼭 넣고 싶은 구성·내용을 적으면 반영돼요

4“글 생성하기” → 제목·본문·태그 미리보기 확인

4. 에디터에 채우기 → 발행

  1. 네이버 블로그 글쓰기 페이지를 엽니다.
  2. 사이드패널에서 “에디터에 채우기” 클릭 → 제목·본문이 자동 입력돼요.
  3. 내용을 검수하고, 이미지·서식을 다듬은 뒤 직접 발행합니다.
스마트에디터는 자체 편집 방식을 써서, 사이트 업데이트 시 자동 입력이 일시적으로 어긋날 수 있어요. 그럴 땐 글쓰기 페이지를 새로고침한 뒤 다시 시도해 주세요.

5. 트러블슈팅

  • “글쓰기 페이지를 열어주세요” — 네이버 블로그 글쓰기 화면(주소에 blog.naver.com)에서 눌러야 해요.
  • “스크립트가 아직 로드되지 않았어요” — 글쓰기 페이지를 새로고침한 뒤 다시 시도.
  • 키 오류 — 사이드패널 API 키 카드의 “변경”으로 다시 저장.
