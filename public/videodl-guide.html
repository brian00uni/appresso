📥 VideoDL Studio 사용 가이드

더우인 · 틱톡 · 레드노트(샤오홍슈)에서 영상을 한 번에 추출·다운로드하는 Chrome 익스텐션

1. 설치

  1. 확장앱 zip 받기 — 랜딩 페이지의 “확장앱 다운로드 (.zip)” 버튼
  2. Chrome 주소창에 chrome://extensions 입력
  3. 우측 상단 개발자 모드 토글 ON
  4. zip을 풀어 생긴 videoDlStudio 폴더를 “압축해제된 확장 프로그램을 로드”로 선택 (또는 zip을 페이지에 드래그 앤 드롭)
  5. 목록에 VideoDL Studio가 나타나면 완료
우측 상단 퍼즐 아이콘 → VideoDL Studio 핀 고정 → 아이콘 클릭 시 사이드패널이 우측에 열립니다.

3. 기본 사용 흐름

1카드 선택 — 지원 사이트 검색 결과 페이지로 가면 각 카드에 체크박스가 자동 표시됩니다. 다운로드할 카드를 클릭해 체크합니다.

2미디어 추출 — 하단 N개 선택됨 / 미디어 추출 버튼 클릭. 익스텐션이 백그라운드에서 각 상세페이지를 차례로 열어 영상 URL을 추출하고, 진행 상황을 사이드패널에서 실시간으로 보여줍니다. 완료된 탭은 자동으로 닫힙니다.

3다운로드 — 사이드패널 하단 전체 다운로드(N)로 모든 미디어를 한 번에 받습니다. 각 카드의 ⬇ 아이콘으로 개별 다운로드도 가능합니다.

4초기화 — 다운로드가 끝나면 세션·로그·선택이 자동 초기화됩니다. 수동으로 비우려면 사이드패널 하단 초기화 버튼을 누릅니다.

4. 다운로드 폴더 구조

브라우저 기본 다운로드 폴더 안에 다음 형식으로 자동 분류 저장됩니다.

~/Downloads/
└── videodl-studio/
    └── 2026-07-04/              ← 날짜 (YYYY-MM-DD)
        └── 13_32_50_tiktok/     ← HH_MM_SS_플랫폼
            ├── video1.mp4
            ├── video2.mp4
            └── video3.mp4

5. 트러블슈팅

  • 추출이 도중에 멈춰요 — TikTok 데이터 로드 전 타임아웃일 수 있습니다. 사이드패널의 재시도 버튼으로 실패한 항목만 다시 추출하세요. 사이트가 로그인을 요구하면 새 탭에서 로그인 후 재시도합니다.
  • 카드에 체크박스가 안 보여요 — 페이지를 새로고침한 뒤 다시 확인합니다. 사이트 레이아웃 변경으로 일시적으로 호환이 깨질 수 있어요.

6. 알려진 제한 사항

  • 한 세션에서는 같은 플랫폼 카드만 묶어 추출하는 것을 권장합니다. (다른 플랫폼 카드를 섞으면 첫 카드 기준으로 폴더가 잡힙니다.)
  • 매우 긴 영상은 다운로드에 시간이 걸릴 수 있습니다.

7. 업데이트 방법

기존 폴더 위에 새 zip 내용을 덮어쓴 뒤 chrome://extensions에서 다시 로드(새로고침)합니다.
